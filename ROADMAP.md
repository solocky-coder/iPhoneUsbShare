# Roadmap

- Add a proper per-second RX/TX sampler (current UI reports counter-derived values).
- Add automatic unplug/replug retry loop matching the upstream `auto` behavior.
- Add device-profile detection for newer iPhone PIDs/configuration layouts.
- Add an installer/MSIX or WiX package with signed release metadata.
- Add a tray mode for "plug in iPhone and forget it".
- Add a safe restore button to re-enable the PTP interface.
